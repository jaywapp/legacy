# Resume

A React-based portfolio resume / CV website.

## Tech Stack

- React (Create React App)
- styled-components

## Getting Started

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

The production build is output to the `build/` directory and is configured to be hosted at `/resume/`.

## Features

- Bilingual support (Korean / English)
- Experience timeline with projects, roles, and results
- Skills section
- Contact information
